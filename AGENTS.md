# Repository instructions

- Keep this Omarchy setup modular and update-safe.
- Preserve the goal of an idempotent, one-command setup for fresh Omarchy devices.
- Only manage user-owned configuration; never modify Omarchy package files.
- Use the `omarchy-kb` MCP server for Omarchy-specific work when available.
- If the server is unavailable, tell the user before continuing.
- Never commit credentials, secrets, machine identifiers, or personal data.
- Keep documentation concise.
- Keep the repository root limited to active setup, features, tests, and documentation.
- Never run troubleshooting or archived scripts from the main installer; features must be explicitly selected.
